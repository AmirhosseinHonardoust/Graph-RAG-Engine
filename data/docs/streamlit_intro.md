# Streamlit Intro

Streamlit is a Python framework for building interactive data and AI demos without writing a full front-end application. It is often used for portfolio projects because model outputs, charts, and controls can be shown quickly.

In a Graph-RAG demo, Streamlit can provide a question box, answer-mode selector, retrieved passage display, citation view, and similar-document exploration. The interface should make it clear whether the answer is extractive or generated by an optional LLM.

Streamlit is not a replacement for a hardened production UI. Authentication, rate limits, observability, and secure deployment would need additional work.

For this project, Streamlit is best used as a review surface that helps users inspect retrieval results and graph-based context.
